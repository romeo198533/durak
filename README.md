# Дурак

Игра «Дурак» для незрячих на Android. Соперники — компьютер или живые
люди за другим телефоном рядом, по Блютусу или вай-фаю; интернет нужен
только для проверки обновлений.

Интерфейс полностью на русском, рассчитан на работу со скринридером
(TalkBack): все элементы — обычные текстовые, все действия доступны
с клавиатуры и читаются вслух.

## Сборка

APK собирается автоматически на GitHub Actions при каждом изменении
в ветке `main`. Готовый файл лежит во вкладке Actions в артефакте
`durak-apk`. Перед сборкой там же прогоняются партии вхолостую — движок
и провод проверяются без телефона.

Собранный APK не подписан: подпись ставится снаружи, своим ключом
(`bin/sign-durak.sh`), а выпуск выкладывается `bin/release-durak.sh`.
Ключ в репозиторий не кладётся — иначе любой смог бы подписать
«обновление».

Локально собрать в этом окружении нельзя: сборка Android требует
`aapt2`, который Google выпускает только под x86_64, а окружение — ARM.

## Состояние

Игра играется: одиночная партия с одной, двумя или тремя программами за
столом, сдача, раздача заново, настройки голоса и вида, инструкция.
Партия по проводу — на двоих и на троих, по Блютусу и по вай-фаю; она
переживает уход с экрана и сворачивание игры.

Переводного дурака пока нет: перевод меняет весь круг, и он делается
отдельным шагом.
