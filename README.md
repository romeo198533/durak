# Дурак

Игра «Дурак» для незрячих на Android. Соперники — компьютер,
игра идёт без интернета; сеть нужна только для проверки обновлений.

Интерфейс полностью на русском, рассчитан на работу со скринридером
(TalkBack): все элементы — обычные текстовые, все действия доступны
с клавиатуры и читаются вслух.

## Сборка

APK собирается автоматически на GitHub Actions при каждом изменении
в ветке `main`. Готовый файл лежит во вкладке Actions в артефакте
`durak-debug`.

Локально собрать в этом окружении нельзя: сборка Android требует
`aapt2`, который Google выпускает только под x86_64, а окружение — ARM.
